# Northstar Corporate Card Onboarding – Business Process Improvement

## Project Overview
This portfolio project examines a simulated corporate card onboarding process and identifies opportunities to improve process efficiency, case handling, and stakeholder coordination.

## Project Objectives
- Understand the existing onboarding process
- Identify process delays and operational issues
- Model an improved future-state process
- Compare selected processing times
- Document proposed business process improvements

## Process Models
This project includes:

- **As-Is Process:** Represents the existing onboarding workflow and identified pain points.
- **To-Be Process:** Represents the proposed improved workflow, including escalation handling and relationship manager coordination.

The process diagrams were created using Bizagi Modeler.

## Key Process Improvement
The proposed To-Be process introduces clearer escalation follow-up and relationship manager availability handling to support more structured case resolution.

## Processing Time Comparison
The project compares simulated processing times for selected stages:

| Stage | As-Is | Proposed To-Be |
|---|---:|---:|
| Internal Verification | 5 business days | 3 business days |
| Compliance Checks | 4 business days | 2 business days |
| Final Approval | 3 business days | 1 business day |
| **Total for these stages** | **12 business days** | **6 business days** |

This represents a proposed 50% reduction across these selected stages only. These figures are simulated project assumptions and are not measured production results.
